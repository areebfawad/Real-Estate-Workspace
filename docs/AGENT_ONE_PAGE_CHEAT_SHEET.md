# Marina Gate — Agent Quick Guide (1 page)

**Objective:** publish a complete property in **under 10 minutes**. Intended to become the handed-out one-page agent guide during week six.

## Step 1 — Sign in

Open the agency website and tap **Agent login**. Enter your own agency email and password. Never use another agent's account. Demo-only credentials are generated in `data/demo-credentials.txt`.

## Step 2 — Add your listing

Open **Listings → Add listing**. Fill in the property title, unique reference number (e.g. MGP-0201), Buy/Rent, Dubai area, property type, AED price, bedrooms, bathrooms, and square footage. Choose furnished/unfurnished and current status. **Keep reference numbers identical to the spreadsheet and photo-folder labels.**

## Step 3 — Describe & highlight

Add a concise description and tick the amenities that apply. Add approximate property map coordinates when available. Tick **Featured** if the listing should receive a homepage spotlight.

## Step 4 — Upload photos

Choose up to 20 original photos. The browser compresses and resizes each one before upload. The **first photo is the cover**. Remove any duplicate or incorrect image. If a photo fails, use a smaller JPG and retry; contact the administrator for persistent issues.

## Step 5 — Save and verify

Select **Active** to publish or **Draft** to keep it private. Click **Create property / Save property changes**. Open the public listing and verify title, price, count, image order and WhatsApp contact.

## Step 6 — Handle your leads

Open **Inquiries**. Each lead has the property reference, name, contact details, email status and a message. Update stage: **New → Contacted → Qualified → Closed**. You can export **your own** lead CSV.

## Golden rules

- You can only manage **your own** listings and inquiries; the manager sees all.
- Do not share passwords or client personal data through unapproved channels.
- Do not send false sale/rental prices or post a listing without correct photos.
- If an inquiry email says **Demo: not sent** or **Failed**, the lead record still exists; contact the manager if live notification is expected.
- For a sold/rented property, change its status so clients no longer treat it as active inventory.

**Administrator escalation:** if ownership, reference number or images are incorrect, ask the manager to correct the account/listing assignment. New agent accounts and access are controlled by the administrator.
